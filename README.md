# HB's Enhanced Wandering Traders

## Overview

    HB's Enhanced Wandering Traders is a Minecraft mod that enhances the behavior and functionality of Wandering Traders
    
    - Makes traders spawn at designated structures instead of randomly in the world. They will change their wares and respawn over time.
    - Allows fully configurable trades via a JSON config file
    - Changes the default currency to any item, default is iron nuggets
    - All trades are reversible, allowing players to buy or sell goods
    - Trades are organized and with a more organized UI
